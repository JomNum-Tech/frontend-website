# JomNum Tech Website

## Product Overview
JomNum Tech Website is a modern, responsive platform built to showcase courses, instructors, and information about JomNum Tech. The website serves as both a public-facing portal for prospective students and visitors, as well as an administrative system for managing users, roles, and content.

## Key Features
- **Public-facing website** with course listings, instructor information, and contact details
- **Admin panel** for user management, role assignment, and file storage
- **Authentication system** with role-based access control
- **File storage system** using Vercel Blob for admin file management

## User Roles
The system supports three user roles:
- **Admin**: Full access to admin panel and management features
- **Student**: Access to student-specific features and content
- **Normal**: Basic user access with limited permissions

## Core Functionality
- Course browsing and information
- User authentication and registration
- Role-based access control
- File upload and management
- User statistics and analytics
